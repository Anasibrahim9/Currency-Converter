# Currency Converter 💱

A responsive currency converter built with **HTML, CSS, and JavaScript** that fetches exchange rates through an API and dynamically updates currency flags and conversion results.

## Features

* Real-time exchange rate fetching via API
* Supports multiple currencies
* Dynamic country flags
* Input validation
* Responsive UI

## Tech Stack

* HTML5
* CSS3
* JavaScript
* REST API
* DOM Manipulation
* Async/Await & Fetch API

## What I Practiced

* API integration
* Asynchronous JavaScript
* DOM manipulation
* Dynamic UI updates
* Handling user input
